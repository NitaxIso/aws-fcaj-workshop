# NHẬT KÝ TUẦN 2: THIẾT LẬP MẠNG VPC VÀ VẬN HÀNH MÁY CHỦ EC2

* **Thời gian:** 21/09/2026 – 25/09/2026
* **Mục tiêu tuần:**
  * Nắm vững kiến thức nền tảng mạng trong AWS thông qua Amazon Virtual Private Cloud (VPC).
  * Triển khai, kết nối và quản trị máy chủ ảo Amazon Elastic Compute Cloud (EC2).
  * Thực hành gán Security Group, phân định Public/Private Subnet và định tuyến Internet Gateway.

### Kết quả đạt được (Achievements)
1. Tự thiết kế và cấu hình hoàn chỉnh mạng VPC đa tầng (Public Subnet và Private Subnet) tại Singapore.
2. Thành thạo quy trình khởi tạo máy chủ EC2, quản lý SSH Key Pair và gán Security Group chính xác theo từng cổng dịch vụ.
3. Hiểu rõ quy trình tự động hóa cấu hình dịch vụ qua User Data và kiểm soát vòng đời máy chủ/ổ đĩa EBS.
